`persistence.yml` chooses the database that stores accounts and sets up the connection to it. [Database](../../admins/guides/network/database/index.mdx) explains the choice, upgrades and sharing a database between proxies.

The database is opened on startup: changes take effect on the next start. A database that cannot be reached stops the startup.

<Setting
  name="type"
  depth={2}
  takes='`"SQLITE"`, `"H2"`, `"MYSQL"`, or `"POSTGRES"`'
  default='`"SQLITE"`'
  affects="which database stores the accounts"
>

Values are case-sensitive. Identica uses SQLite when the file does not set `type`. Any other value stops the startup with an error that names the accepted values, and the file is left as it is, so Identica never runs on a database the file did not ask for.

`"MYSQL"` works with MySQL 8.0.19 or newer and with MariaDB.

</Setting>

## Fields of each type

Each type has fields of its own. After changing `type`, start the proxy once so Identica writes the new type's fields, then fill them in.

<ContentTabs items={["SQLite", "H2", "MySQL", "PostgreSQL"]}>
  <ContentTab value="SQLite">
    <Setting
      name="file"
      depth={4}
      takes="a file name or relative path"
      default='`"identica.db"`'
      affects="the SQLite file, relative to the data directory"
    >

    A blank value uses `identica.db`.

    </Setting>
  </ContentTab>
  <ContentTab value="H2">
    <Setting
      name="file"
      depth={4}
      takes="a file name, relative path, or direct H2 target"
      default='`"identica"`'
      affects="the H2 database"
    >

    If the value starts with `mem:`, `tcp:`, `ssl:`, or `file:`, Identica treats it as a direct H2 target and passes it to H2 unchanged; H2 refuses a `file:` path relative to the working directory, so such a path must be absolute or start with `./` or `~/`.
    Otherwise it is treated as a file path relative to the plugin data directory, and Identica gives H2 its absolute path.

    </Setting>

    <Setting
      name="options"
      depth={4}
      takes="a string"
      default='`""`'
      affects="H2 connection options, such as `MODE=MySQL`"
    >

    Identica appends them to the connection, separated by `;`.

    </Setting>
  </ContentTab>

## hikari

The connection pool, [HikariCP](https://github.com/brettwooldridge/HikariCP#gear-configuration-knobs-baby). The defaults suit almost every network; change them for a reason such as a connection limit of your database server.

</Setting>
