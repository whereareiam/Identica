### Настройте функции провайдеров [step]

Все реализации функций уже входят в сборку Identica. Общие значения по умолчанию задаются в `features/`, а переопределения для каждого провайдера — в `providers[].features`. Провайдер должен объявить поддержку выбранного поведения.

Примеры и карту путей к настройкам смотрите на странице [Функции](../../configuration/features/index.mdx). Признаки провайдера, например ники, за которые отвечает провайдер, описывают гарантии идентификации и не являются переключателями функций.
