Каждая функция хранит свои файлы в `features/<feature>/`: `settings.yml`, а также `messages.yml` и `commands.yml`, если у неё есть сообщения или команды. Ограничение входа вложено в `features/restriction/join/`. Что делает каждая функция, описано в разделе [Функции](../../admins/features/index.mdx).

## Настройки для отдельных провайдеров [#per-provider-settings]

Запись провайдера в [`providers/providers.yml`](../providers/index.mdx#features) может задать собственное значение функции в `features`. Всё, что она не указывает, берётся из общих настроек функции:

| Функция | Общие настройки | Для провайдера | Наследует |
| --- | --- | --- | --- |
| Распознавание | `features/recognition/settings` | `features.recognition` | `enabled`, а также `defaultSignals` для `signals` |
| Ограничения | `features/restriction/settings` | `features.restriction.enabled` | `enabled` |
| Ограничение входа | `features/restriction/join/settings` | `features.restriction.join` | `enabled`, `allow` |
| Sentinel | `features/sentinel/settings` | `features.sentinel.enabled` | `enabled` |
| Верификация | `features/verification/settings` | `features.verification` | всё, что в `defaults` |

`enabled: false` у провайдера выключает функцию только для этого провайдера, а `enabled: true` включает её, даже когда общее значение — `false`. `features.restriction.enabled: false` у провайдера выключает для него и ограничение входа.

Провайдер должен поддерживать функцию. Если включить функцию для провайдера, который её не поддерживает, этот провайдер не загрузится. Оба официальных провайдера поддерживают все функции.
