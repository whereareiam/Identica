For support with Identica, use one of these channels:

- [Discord](https://discord.arcadeya.com) is the recommended option for normal support, setup questions, and faster back-and-forth troubleshooting.
- [GitHub issues and pull requests](https://github.com/whereareiam/Identica) are a good option for bug reports, feature requests, and changes that should stay visible and tracked.

## Response expectations

Critical fixes are usually handled quickly.
If an issue could be exploited or could seriously affect running servers, report it privately as described in the [security policy](https://github.com/whereareiam/Identica/security/policy) instead of posting details in a public issue or on Discord.

Normal fixes, improvements, and lower-priority bugs are usually prioritized lower and may be handled over a longer period rather than immediately.
