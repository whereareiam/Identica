Официальный провайдер `premium` аутентифицирует лицензионные аккаунты Minecraft. Установите его по [руководству по установке](../../../installation/normal/index.mdx), включите в разделе [Провайдеры](../../../configuration/providers/index.mdx) и настройте его [параметры провайдера](./configuration/settings/index.mdx).

Premium объявляет гарантию `OWNED_USERNAME`. Identica следует подтверждённому им нику, если администратор не назначил ник вручную, а [правила конфликтов ников](../../../configuration/identity/username/index.mdx#default-rules) по умолчанию отдают владельцу лицензионного аккаунта ник, которым владеет аккаунт Credential; это поведение идентичности, а не переключаемая функция.

Premium поддерживает распознавание, верификацию, ограничения и проверки Sentinel. Какое поведение применяется, определяют общие значения по умолчанию и его переопределения в `providers[].features`.

## Перенос аккаунта на другой провайдер [#moving-an-account-to-another-provider]

Premium требует от каждого игрока, который заходит с ником аккаунта Premium, войти с этим лицензионным аккаунтом, поэтому офлайн-клиент не может занять такой ник. Ожидающая миграция этого не меняет.

Владелец переносит аккаунт на Credential командами `/credential` и `/credential confirm`, уже выполнив вход. После этого Identica отключает игрока. При следующем входе игрок ещё раз входит с лицензионным аккаунтом, и этот вход позволяет ему задать пароль, которым он будет пользоваться дальше. Premium следует общему правилу [переноса аккаунта на другой провайдер](../../index.md#moving-an-account-between-providers).
