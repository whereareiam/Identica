`providers/providers.yml` включает провайдеры и задаёт их порядок, имена хостов, а также их собственные настройки сессий и функций. Собственные настройки каждого провайдера лежат в его папке рядом с этим файлом. Как используются порядок и имена хостов, описано в разделе [Как выбирается провайдер](../../admins/guides/logins/provider-selection/index.mdx).

## behavior

<Setting
  name="attemptTtl"
  takes="положительную длительность"
  default='`"10m"`'
  affects="как долго Identica помнит, что провайдер уже пробовали для этого ника и адреса"
  flag="advanced"
>

Игрок, у которого не удался лицензионный вход, например офлайн-клиент с ником лицензионного аккаунта, переходит к следующему провайдеру, если в течение этого времени снова зайдёт с того же адреса. Чем больше значение, тем дольше сохраняется этот выбор; чем меньше, тем раньше провайдера пробуют снова.

</Setting>

<Setting
  name="providers"
  depth={2}
  takes="список записей провайдеров"
  affects="какие провайдеры загружаются и как участвует каждый из них"
>

Identica загружает провайдер, только если у него есть запись здесь с `enabled: true`.

<Tabs items={["YAML", "JSON"]}>
  <Tab value="YAML">
```yaml
behavior:
  attemptTtl: "10m"
providers:
  - id: "premium"
    displayName: "Premium"
    enabled: true
    priority: 100
    entrypoints:
      - "premium.example.com"
    session:
      concurrencyPolicy: "REJECT_NEW"
  - id: "credential"
    displayName: "Credential"
    enabled: true
    priority: 50
    entrypoints:
      - "credential.example.com"
```
  </Tab>
  <Tab value="JSON">
```json
{
  "behavior": {
    "attemptTtl": "10m"
  },
  "providers": [
    {
      "id": "premium",
      "displayName": "Premium",
      "enabled": true,
      "priority": 100,
      "entrypoints": ["premium.example.com"],
      "session": {
        "concurrencyPolicy": "REJECT_NEW"
      }
    },
    {
      "id": "credential",
      "displayName": "Credential",
      "enabled": true,
      "priority": 50,
      "entrypoints": ["credential.example.com"]
    }
  ]
}
```
  </Tab>
</Tabs>

</Setting>

<Setting
  name="id"
  takes="id провайдера, например `premium` или `credential`, в любом регистре"
  affects="какой установленный провайдер настраивает эта запись"
>

</Setting>

<Setting
  name="displayName"
  takes="строку"
  default='`""`'
  affects="название провайдера в сообщениях игрокам, например при выборе провайдера"
>

Если значение пустое, используется собственное имя провайдера.

</Setting>

<Setting
  name="enabled"
  takes="`true` или `false`"
  affects="загружается ли провайдер и предлагается ли он игрокам"
>

</Setting>

<Setting
  name="priority"
  takes="целое число"
  affects="какой провайдер побеждает, когда у нескольких есть одинаково веская причина обработать игрока"
>

Побеждают большие значения.

</Setting>

<Setting
  name="entrypoints"
  takes="список имён хостов в формате `host` или `host:port`"
  affects="какие имена хостов выбирают этого провайдера для заходящего игрока"
>

Запись `host` подходит для имени хоста на любом порту, `host:port` — только на этом порту. Если одно имя хоста указано у нескольких провайдеров, его получает провайдер с большим `priority`. Оставьте список пустым, если все ваши игроки заходят через один адрес. См. [Имена хостов](../../admins/guides/logins/provider-selection/index.mdx#hostnames).

</Setting>

<Setting
  name="session.concurrencyPolicy"
  takes='`"REPLACE_EXISTING"` или `"REJECT_NEW"`'
  default="не задано"
  affects="что происходит, когда аккаунт этого провайдера входит со второго подключения"
  flag="advanced"
>

Если значение не задано, провайдер следует [`sessions.concurrencyPolicy`](../settings/index.mdx#concurrencypolicy) из `settings.yml`.

</Setting>

<Setting
  name="features"
  takes="объект с записью для каждой функции"
  default="не задано"
  affects="собственные настройки функции для этого провайдера"
>

Всё, что запись не указывает, берётся из общих настроек функции. Провайдер должен поддерживать функцию: если включить функцию, которую провайдер не поддерживает, провайдер не загрузится.

| Ключ | Страница |
| --- | --- |
| `features.recognition` | [Распознавание](../features/recognition/index.mdx#per-provider) |
| `features.restriction.enabled` | [Ограничения](../features/restriction/index.mdx#per-provider) |
| `features.restriction.join` | [Ограничение входа](../features/restriction/join/index.mdx#per-provider) |
| `features.sentinel.enabled` | [Sentinel](../features/sentinel/index.mdx#per-provider) |
| `features.verification` | [Верификация](../features/verification/index.mdx#per-provider) |

См. [Функции](../../admins/features/index.mdx#on-for-everyone-or-per-provider).

</Setting>
