Пустой файл `type=YAML` указывает Identica записывать файлы в формате YAML. Чтобы использовать JSON, переименуйте его в `type=JSON` до того, как менять какие-либо настройки: уже существующие файлы Identica не конвертирует. Все файлы описаны в разделе [Конфигурация](../../../configuration/index.mdx).
