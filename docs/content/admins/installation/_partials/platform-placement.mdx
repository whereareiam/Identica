Identica comes in two forms; use one of them:

- `Identica-BUNDLE-<version>.jar` runs on every supported proxy.
- `Identica-PLATFORMS-<version>.zip` holds one jar per proxy: `Identica-VELOCITY-<version>.jar` and `Identica-BUNGEECORD-<version>.jar`.

The Identica jar goes into the proxy's `plugins/` directory. The provider jars go into the `providers/` directory inside Identica's data directory, which you create yourself before the first start. Never put a provider jar directly into `plugins/`.
