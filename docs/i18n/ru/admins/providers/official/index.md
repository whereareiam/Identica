Официальные провайдеры выходят вместе с Identica — на тех же страницах и с той же версией.

- [Premium](./premium/index.md) позволяет игрокам входить через лицензионный аккаунт Minecraft и сохраняет их аккаунт, когда они меняют ник в Mojang.
- [Credential](./credential/index.md) позволяет игрокам входить по паролю — для игроков без лицензионного аккаунта.

Оба поддерживают все [функции](../../features/index.mdx).
