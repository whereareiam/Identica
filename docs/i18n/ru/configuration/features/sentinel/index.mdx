Sentinel добавляет защиту, которая отслеживает повторяющиеся или рискованные действия.
В Identica есть разные типы таких проверок: одни действуют широко, другие — только для конкретного провайдера или процесса провайдера.

Sentinel встроен в Identica. Его общая настройка `enabled` задаёт значение по умолчанию для проверок, принадлежащих провайдерам; провайдеры могут переопределить `features.sentinel.enabled`. Глобальные проверки подключений используют общие настройки, потому что выполняются до того, как провайдер становится известен. Подробнее — в разделе [Настройки](./settings/index.mdx).
