Community providers are provider modules made by the community and not maintained by Identica developers.
They still participate directly in Identica's provider flow.

This page is the routing point for unofficial and community-maintained Identica providers.

## Add a provider

If you want a community provider to be listed here, request it through one of these channels:

- [Discord](https://discord.arcadeya.com)
- [GitHub Issues or Pull Requests](https://github.com/whereareiam/Identica)

Community providers can eventually be listed here as internal docs pages, external documentation links, or both.
