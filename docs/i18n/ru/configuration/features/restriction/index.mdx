Функция `restriction` — это встроенный каркас для типов ограничений, сигналов и действующих ограничений. Её глобальное значение `enabled` по умолчанию можно переопределить для каждого провайдера в `features.restriction.enabled`.

Общие настройки ограничений находятся в `features/restriction/settings`.
Переопределения ограничений для конкретного провайдера задаются в `providers[].features.restriction`.

## Типы ограничений [#restriction-types]

[Ограничение входа](./join/index.mdx) предоставляет отдельная функция `restriction-join`. Для неё также нужно выбрать `restriction`. Если выбрать только каркас, команды и проверки ограничения входа не устанавливаются.
