Identica runs on a Velocity, BungeeCord or Waterfall proxy. This page installs it with the two official providers, [Credential](../providers/official/credential/index.md) and [Premium](../providers/official/premium/index.md), on one proxy. When it is done, continue with [First configuration](../first-configuration/index.mdx).

To run Identica on several proxies that share their players, install it on each proxy as described here, then follow [Running several proxies](../guides/network/several-proxies/index.mdx).

## Before you start

- a Velocity, BungeeCord or Waterfall proxy running on Java 21 or newer
- at least one backend server for players who are logging in, and the servers they play on afterwards
- internet access from the proxy on the first start, when Identica downloads its libraries

All features of Identica, such as two-factor verification, are part of the plugin. Nothing else needs to be installed for them; they are turned on in the configuration.
