Провайдер — это один из способов входа для игроков: например, по паролю или через лицензионный аккаунт Minecraft. Сама Identica отвечает за аккаунты, сессии, ники и маршрутизацию, а каждый провайдер решает, может ли игрок продолжить. В сети работают те провайдеры, которые ей нужны, бок о бок.

## Официальные провайдеры и провайдеры от сообщества [#official-and-community-providers]

- [Официальные провайдеры](./official/index.md) поддерживают разработчики Identica, и они описаны здесь: [Credential](./official/credential/index.md) для входа по паролю и [Premium](./official/premium/index.md) для лицензионных аккаунтов.
- [Провайдеры от сообщества](./community/index.md) создают другие люди. У них могут быть свой график релизов, своя поддержка и своя документация — внимательно изучите такой провайдер, прежде чем устанавливать его.

## Добавление провайдера [#adding-a-provider]

1. Положите jar-файл провайдера в папку `providers/` в папке данных Identica, рядом с официальными.
2. Добавьте для него запись в `providers/providers.yml` с его идентификатором, `enabled: true` и `priority`. Identica загружает провайдер, только если у него есть включённая запись.
3. Запустите прокси или перезапустите его. Провайдер запишет свои файлы в собственную папку внутри `providers/`.

Какой провайдер достанется заходящему игроку, объясняет страница [Как выбирается провайдер](../guides/logins/provider-selection/index.mdx). Игроки могут перенести аккаунт с одного провайдера на другой — см. [Переход между провайдерами](../guides/accounts/moving-between-providers/index.mdx).

Чтобы написать собственный провайдер, см. [Написание провайдера](../../developers/extending/providers/index.mdx).
