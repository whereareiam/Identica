Если ваша хостинг-панель ограничивает число отдельных бэкенд-серверов, которые можно запустить, поможет лёгкий лимбо-сервер.
Например, [PicoLimbo](https://picolimbo.quozul.dev/about/introduction.html) работает вместе с Velocity и даёт виртуальную точку маршрутизации, размещённую на стороне прокси, — без ещё одного полноценного игрового сервера.
