Identica работает на прокси Velocity, BungeeCord или Waterfall. На этой странице описана установка на один прокси вместе с двумя официальными провайдерами — [Credential](../providers/official/credential/index.md) и [Premium](../providers/official/premium/index.md). Когда закончите, переходите к странице [Первоначальная настройка](../first-configuration/index.mdx).

Чтобы запустить Identica на нескольких прокси с общими игроками, установите её на каждый прокси так, как описано здесь, а затем следуйте руководству [Несколько прокси](../guides/network/several-proxies/index.mdx).

## Что понадобится [#before-you-start]

- прокси Velocity, BungeeCord или Waterfall на Java 21 или новее
- хотя бы один бэкенд-сервер для игроков, которые входят, и серверы, на которых они играют после входа
- доступ прокси в интернет при первом запуске, когда Identica скачивает свои библиотеки

Все функции Identica, например двухфакторное подтверждение, входят в сам плагин. Отдельно для них ничего устанавливать не нужно — они включаются в конфигурации.
