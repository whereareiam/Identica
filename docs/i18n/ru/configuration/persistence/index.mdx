`persistence.yml` выбирает базу данных, в которой хранятся аккаунты, и настраивает подключение к ней. Руководство [База данных](../../admins/guides/network/database/index.mdx) объясняет выбор базы, обновления и общую базу данных для нескольких прокси.

База данных открывается при запуске: изменения вступают в силу при следующем запуске. Если до базы данных не удаётся достучаться, запуск останавливается.

<Setting
  name="type"
  depth={2}
  takes='`"SQLITE"`, `"H2"`, `"MYSQL"` или `"POSTGRES"`'
  default='`"SQLITE"`'
  affects="то, в какой базе данных хранятся аккаунты"
>

Значения чувствительны к регистру. Если в файле не задан `type`, Identica использует SQLite. Любое другое значение останавливает запуск с ошибкой, в которой перечислены допустимые значения, а файл при этом не меняется, так что Identica никогда не работает с базой данных, которая не указана в файле.

`"MYSQL"` работает с MySQL 8.0.19 и новее, а также с MariaDB.

</Setting>

## Поля каждого типа [#fields-of-each-type]

У каждого типа свои поля. Сменив `type`, запустите прокси один раз, чтобы Identica записала поля нового типа, а затем заполните их.

<ContentTabs items={["SQLite", "H2", "MySQL", "PostgreSQL"]}>
  <ContentTab value="SQLite">
    <Setting
      name="file"
      depth={4}
      takes="имя файла или относительный путь"
      default='`"identica.db"`'
      affects="файл SQLite относительно папки данных"
    >

    Если значение пустое, используется `identica.db`.

    </Setting>
  </ContentTab>
  <ContentTab value="H2">
    <Setting
      name="file"
      depth={4}
      takes="имя файла, относительный путь или прямой адрес H2"
      default='`"identica"`'
      affects="базу данных H2"
    >

    Если значение начинается с `mem:`, `tcp:`, `ssl:` или `file:`, Identica считает его прямым адресом H2 и передаёт его H2 без изменений; H2 не принимает путь `file:` относительно рабочего каталога, поэтому такой путь должен быть абсолютным или начинаться с `./` или `~/`.
    В остальных случаях оно считается путём к файлу относительно папки данных плагина, и Identica передаёт H2 его абсолютный путь.

    </Setting>

    <Setting
      name="options"
      depth={4}
      takes="строку"
      default='`""`'
      affects="параметры подключения H2, например `MODE=MySQL`"
    >

    Identica добавляет их к подключению через `;`.

    </Setting>
  </ContentTab>
  <ContentTab value="MySQL">
    Этот тип подходит и для MySQL, и для MariaDB.

    - Нужна MySQL 8.0.19 или новее. На более старом сервере MySQL Identica останавливает запуск ещё до того, как создаст или изменит какую-либо таблицу, и выводит ошибку с найденной и требуемой версиями. Как и при любом неудачном запуске, все подключения отклоняются, пока сервер не будет обновлён, а прокси — перезапущен.
    - Минимальной версии MariaDB Identica не требует.

## hikari

Пул подключений [HikariCP](https://github.com/brettwooldridge/HikariCP#gear-configuration-knobs-baby). Значения по умолчанию подходят почти любой сети; меняйте их, только если есть причина, например ограничение числа подключений на сервере базы данных.

<Setting
  name="poolName"
  takes="строку"
  default='`"Identica"`'
  affects="имя пула в логах"
  flag="advanced"
>

</Setting>

</Setting>
