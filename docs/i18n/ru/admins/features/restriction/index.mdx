Ограничения позволяют персоналу ограничить провайдер прямо во время работы сети, не редактируя файлы и не перезапуская прокси. Ограничение включается командой и действует, пока персонал его не снимет или пока не истечёт его срок.

Сейчас в Identica один вид ограничений: [ограничение входа](./join/index.mdx), которое закрывает провайдер для новых входов, кроме игроков, которым он доверяет.

## Сколько действует ограничение [#how-long-a-restriction-lasts]

Ограничение действует, пока персонал его не снимет или пока не пройдёт `toggleTtl` из `features/restriction/settings`, по умолчанию 365 дней, — смотря что наступит раньше.

Ограничения не хранятся в базе данных:

- С [репликацией](../../guides/network/several-proxies/index.mdx) они хранятся в Redis. Каждый прокси сети видит ограничение сразу после его включения или снятия, а перезапущенный прокси видит его, пока оно есть в Redis.
- Без репликации они хранятся в памяти прокси, поэтому перезапуск прокси снимает все ограничения. После перезапуска включите их снова.

## Отключение ограничений [#turning-restrictions-off]

`enabled: false` в `features/restriction/settings` отключает все виды ограничений для всех провайдеров. `features.restriction.enabled: false` у провайдера отключает их только для этого провайдера.

Все настройки описаны на странице [Настройки ограничений](../../../configuration/features/restriction/index.mdx).
