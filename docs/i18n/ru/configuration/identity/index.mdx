Гарантии провайдеров описывают, что реализации провайдеров гарантируют о своих идентичностях. Это не объявления функций, которые пользователь может включать и выключать.

[Ник](./username/index.mdx) описывает, как ники следуют за провайдерами, ники, назначенные вручную, и правила, которые решают, когда два аккаунта хотят один ник.
