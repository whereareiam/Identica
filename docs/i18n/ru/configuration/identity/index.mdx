Признаки провайдеров (traits) описывают гарантии, которые дают реализации провайдеров. Это не объявления функций, которые пользователь может включать и выключать.

[Право на ник](./username/index.mdx) описывает ники, за которые отвечает провайдер, ручные переопределения и политику конфликтов.
