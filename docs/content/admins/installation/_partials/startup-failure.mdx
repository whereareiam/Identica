<Callout type="error" title="A failed startup closes the proxy to players">
  If Identica cannot finish its startup, for example because a configuration file is invalid or a required library could not be downloaded, the proxy keeps running but Identica refuses every connection with the game's own message for unavailable authentication servers, shown in each player's language. Nobody reaches a backend server without authentication. Read the error in the proxy console, fix its cause, and restart the proxy.
</Callout>
