`features/restriction/settings.yml` содержит настройки, общие для всех видов ограничений. Что делают ограничения, описано в разделе [Ограничения](../../../admins/features/restriction/index.mdx).

## settings.yml

<Setting
  name="enabled"
  takes="`true` или `false`"
  default="`true`"
  affects="можно ли использовать ограничения — для каждого провайдера, который не задаёт собственное значение"
>

</Setting>

<Setting
  name="toggleTtl"
  takes="положительную длительность"
  default='`"365d"`'
  affects="сколько ограничение, включённое администрацией, действует, прежде чем снимется само"
>

Ограничение действует, пока администрация его не снимет или пока не пройдёт эта длительность — смотря что наступит раньше. Без [репликации](../../replication/index.mdx) все ограничения снимает и перезапуск прокси.

</Setting>

<Setting
  name="replication.toggleNamespace"
  takes="непустую строку"
  default='`"identica:restriction:toggle"`'
  affects="имя, под которым прокси делятся действующими ограничениями"
  flag="advanced"
>

Прокси, которые должны делить ограничения, используют одно и то же значение.

</Setting>

## Для отдельного провайдера [#per-provider]

<Setting
  name="features.restriction.enabled"
  takes="`true` или `false`"
  default="не задано"
  affects="можно ли использовать ограничения для этого провайдера"
>

Если значение не задано, применяется общее `enabled`. `false` также выключает для провайдера [ограничение входа](./join/index.mdx).

</Setting>
