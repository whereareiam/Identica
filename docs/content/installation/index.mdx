# Installation

Identica installation is split into two operator paths:

- [Normal installation](./normal/index.mdx) for simple usage without replication or restart-surviving cache
- [Advanced installation](./advanced/index.mdx) for setups where state should survive restarts or be shared across multiple runtimes

## Download paths

<ContentTabs items={["GitHub Releases", "GitHub Development Builds", "Modrinth Releases"]}>
  <ContentTab value="GitHub Releases">
    Use [GitHub releases](https://github.com/whereareiam/Identica/releases) when you want stable published versions.

    This path is best when you want a normal released build and matching released provider jars.
  </ContentTab>
  <ContentTab value="GitHub Development Builds">
    Use [Development builds](https://github.com/whereareiam/Identica/actions/workflows/development.yml) when you want the newest build from the `dev` branch.

    This path is best when you want the latest changes before they are packaged as a release.
  </ContentTab>
  <ContentTab value="Modrinth Releases">
    Use Modrinth when you want published downloads from the project pages:

    - [Identica](https://modrinth.com/plugin/identica)
    - [Identica Premium Provider](https://modrinth.com/plugin/identica-premium-provider)
    - [Identica Credential Provider](https://modrinth.com/plugin/identica-credential-provider)

    This path is best when you prefer released downloads from the Modrinth project pages.
  </ContentTab>
</ContentTabs>

Both installation guides explain which files you need and how to download them from those sources.

## Built-in features

All built-in features and identity behavior are compiled into Identica. Configure shared defaults under `features/` and provider overrides under `providers[].features`. No separate feature installation is needed.

See [Features](../configuration/features/index.mdx) for configuration and [Feature configuration migration](./feature-migration/index.mdx) for existing capability-based configurations.

## Provider scope

The installation walkthroughs in this section only cover the official `Password` and `Premium` providers.
That is a documentation scope choice, not a product limit.

Identica is provider-oriented, so official and unofficial providers can be added over time.
Use the [Providers overview](../providers/index.md), [Official providers](../providers/official/index.md), and [Community providers](../providers/community/index.md) pages to discover broader provider options.
