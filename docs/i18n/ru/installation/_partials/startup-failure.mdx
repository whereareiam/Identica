<Callout type="error" title="При неудачном запуске прокси закрыт для игроков">
  Если Identica не может завершить запуск — например, из-за некорректного файла конфигурации или потому что не удалось скачать нужную библиотеку, — прокси продолжает работать, но Identica отклоняет каждое подключение стандартным игровым сообщением о недоступности серверов аутентификации, которое показывается на языке каждого игрока. Без аутентификации никто не попадёт на бэкенд-сервер. Прочитайте ошибку в консоли прокси, устраните её причину и перезапустите прокси.
</Callout>
