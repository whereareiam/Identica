Эти страницы для разработчиков, которые используют Identica в своём коде. Чтобы изменить саму Identica, перейдите в раздел [Участие в разработке](../contributing/building/index.mdx).

| Вы хотите | Что написать | С чего начать |
| --- | --- | --- |
| реагировать на входы, читать аккаунты и сессии или не пропускать чат, пока игрок не вошёл | аддон: отдельный плагин на прокси | [Написание аддона](./extending/addons/index.mdx) |
| добавить способ входа, например через аккаунт на сайте | провайдер: jar-файл, который Identica загружает из папки `providers/` | [Написание провайдера](./extending/providers/index.mdx) |
| хранить свои данные рядом с аккаунтами Identica | таблицы в базе данных Identica | [Схемы базы данных](./extending/database-schemas/index.mdx) |

В любом случае начните с зависимости от API — см. [Начало работы](./api/index.mdx).

В репозитории `examples/addon` и `examples/provider` — полноценный аддон и полноценный провайдер. Живые тесты Identica запускают оба на настоящем прокси, поэтому они всегда соответствуют текущему API.

## Совместимость [#compatibility]

API публикуется с каждым релизом. Типы, методы и события `me.whereareiam.identica:api` и других артефактов `-api` остаются рабочими в пределах мажорной версии. Релиз, который их ломает, — мажорный, и он сообщает об этом в примечаниях к релизу в разделе «For developers».
