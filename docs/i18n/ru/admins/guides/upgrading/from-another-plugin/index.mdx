Identica не поставляется с инструментами импорта из других плагинов авторизации. Аккаунты можно перенести консольными командами, которые скрипт может выполнить для каждого аккаунта прежнего плагина.

Если писать такой скрипт самостоятельно не хочется, спросите в [Discord](https://discord.arcadeya.com): возможно, мы сможем предоставить скрипт, который вы проверите и запустите на своих данных.

## Регистрация аккаунтов из консоли [#registering-accounts-from-the-console]

`/identica credential register <username> <password>` создаёт аккаунт Credential для игрока, который ещё не заходил на сервер с Identica. После этого игрок входит с этим паролем.

Аккаунт получает UUID, зарезервированный за его ником, а без резервирования — тот, который назначает [`uniqueIdMode`](../../accounts/unique-ids/index.mdx). Чтобы игрок сохранил UUID из прежнего плагина, зарезервируйте его непосредственно перед регистрацией аккаунта:

```
identica admin reservation set Steve 5627dd98-e6be-3c21-b8a8-e92344183641
identica credential register Steve <password>
```

Резервирование нужно использовать в пределах `identity.reservationTtl` из `settings.yml`, по умолчанию 15 минут. После этого аккаунт сохраняет этот UUID при любом значении `uniqueIdMode`.

Команда только создаёт аккаунты:

- если ник уже принадлежит аккаунту — в любом регистре и через любой провайдер, — ничего не регистрируется, а команда называет этот аккаунт сообщением `commands.admin.accountExists` из `messages.yml` провайдера Credential;
- если зарезервированный UUID уже принадлежит другому аккаунту, команда отвечает сообщением `commands.admin.reservationTaken` и тоже ничего не регистрирует.

## Пароли [#passwords]

Команда принимает пароль, а не хеш, и хеширует его согласно текущим [настройкам хеширования](../../../providers/official/credential/passwords/index.mdx#hashing) провайдера Credential. Если прежний плагин хранил только хеши, выдайте игрокам временный пароль и попросите сменить его командой `/changepassword`. Позже задать новый пароль можно командой `/identica credential setpassword <username> <password>`.

## Лицензионные игроки [#premium-players]

Лицензионные аккаунты импортировать не нужно: игрок с лицензионным аккаунтом заходит через провайдер Premium и получает аккаунт при первом входе. Если прежний плагин выдавал лицензионным игрокам их лицензионные UUID и ваши бэкенд-серверы хранят данные под ними, используйте `uniqueIdMode: PREMIUM` или резервируйте UUID каждого игрока незадолго до его входа.
