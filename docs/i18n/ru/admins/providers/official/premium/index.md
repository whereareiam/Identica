Провайдер Premium позволяет игрокам входить через лицензионный аккаунт Minecraft, который проверяет Mojang, без пароля. Установите его, как описано в разделе [Установка](../../../installation/index.mdx), и включите в `providers/providers.yml`.

Его файлы лежат в `providers/Premium/`: `settings.yml`, `messages.yml` и `commands.yml`.

## Кого просят войти через лицензионный аккаунт [#who-is-asked-for-a-premium-login]

Для каждого заходящего игрока Premium решает, владеет ли тот лицензионным аккаунтом со своим ником. Такого игрока просят войти через лицензионный аккаунт, и официальный лаунчер делает это сам; все остальные переходят к следующему провайдеру, например Credential. Как Premium принимает это решение и как не отключать пиратских (офлайн) игроков, которые используют ник лицензионного аккаунта, объясняет страница [Определение лицензионных аккаунтов](./detection/index.mdx).

Ник, привязанный к аккаунту Premium, всегда требует входа через лицензионный аккаунт, поэтому офлайн-клиент не может его занять.

## Ники [#usernames]

Premium владеет никами своих игроков: только владелец аккаунта Mojang `Steve` может зайти через Premium как `Steve`. Игрок, который сменил ник своего аккаунта в Mojang, при следующем входе играет под новым ником и сохраняет свой аккаунт.

По [правилам для ников](../../../guides/accounts/usernames/index.mdx) по умолчанию владелец ника забирает его у аккаунта Credential, который зарегистрировал этот ник первым, и тот аккаунт получает другой ник.

## Перенос аккаунтов [#moving-accounts]

| Команда | Что делает |
| --- | --- |
| `/premium` | начинает перенос аккаунта на Premium |
| `/premium confirm` | подтверждает перенос |
| `/premium cancel` | отменяет его |

Игрок переносит аккаунт на Premium, уже выполнив вход, а затем заходит со своим лицензионным аккаунтом. Перенос с Premium на Credential требует ещё одного входа через лицензионный аккаунт, после которого игрок задаёт пароль. См. [Переход между провайдерами](../../../guides/accounts/moving-between-providers/index.mdx).

## Функции [#features]

Premium поддерживает все [функции](../../../features/index.mdx). Лицензионные аккаунты уже защищены входом через Mojang, поэтому многие сети не требуют для них подтверждения.

Все настройки описаны на странице [Настройки](./settings/index.mdx).
