Выберите этот способ, если хотите использовать Identica в простой конфигурации сервера Minecraft без общего состояния, сохраняющегося после перезапуска.
Он рассчитан на несложное использование, простую маршрутизацию и обычную повседневную работу, когда кэш и состояние незавершённых прохождений не обязаны переживать перезапуск плагина.

## Что охватывает руководство [#scope]

Это руководство охватывает базовые задачи установки, которых большинство пользователей ждёт от привычных плагинов авторизации.
<Include src="../_partials/provider-scope.mdx" />

## Что предполагает этот способ [#what-this-path-assumes]

- вам достаточно одного экземпляра Identica
- вам нужна простая конфигурация, а не среда с репликацией
- сессии, кэш и состояние незавершённых прохождений не обязаны переживать перезапуск плагина
- серверу или прокси достаточно простой схемы маршрутизации

Если сессии и незавершённые состояния всё же должны сохраняться после перезапуска плагина, воспользуйтесь [расширенной установкой](../advanced/index.mdx).
Для этого нужно включить репликацию.

### Запустите сервер один раз и остановите его [step]

Запустите платформу один раз, чтобы Identica создала начальные файлы и папки.
Первый запуск нужен только для того, чтобы плагин подготовил структуру конфигурации по умолчанию.
Завершать настройку при этом первом запуске не требуется.

### Замените целевые серверы по умолчанию простым реальным маршрутом [step]

В сгенерированных настройках `routing` по умолчанию указаны примеры целевых серверов.
Не оставляйте их без изменений, если серверов с такими именами в вашей среде на самом деле нет.

<Include src="../_partials/routing-targets.mdx" />

Для простой конфигурации хорошей отправной точкой будет одна общая цель:

```yaml
defaults:
  step:
    target: lobby
  complete:
    target: lobby
```

В сгенерированной конфигурации маршрутизации `scenarios` по умолчанию пуст.
Если в вашей конфигурации аутентификация, регистрация или миграция уже разнесены по разным бэкенд-серверам, добавьте только те сценарии, которые отличаются от этих значений по умолчанию.
В остальных случаях не усложняйте маршрутизацию и используйте одну общую цель.
