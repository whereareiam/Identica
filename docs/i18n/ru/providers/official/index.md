На этой странице перечислены официальные провайдеры, которые сейчас поддерживаются для Identica.
У каждого провайдера в этом разделе есть своя страница.

## Провайдеры [#providers]

- [`Premium`](./premium/index.md)  
  Позволяет игрокам входить с настоящим лицензионным аккаунтом Minecraft и сохраняет их идентичность, даже если ник изменится.

- [`Credential`](./credential/index.md)  
  Для серверов, которым нужен вход по учётным данным для игроков без официального лицензионного аккаунта Minecraft.
